Reelkar v3.0 · Masala Pop

Web mockups of Home and Make a reel, on desktop and phone. Saffron hero, chilli for the main action, mint for AI and wins, plum ink and a deep-plum sidebar and tab bar. Bricolage Grotesque headings, Inter text.

What changes from v2.0. One saffron hero per page carries the number that matters. Actions become an icon grid instead of a form-first page. The sidebar and tab bar go deep plum, so the page has a strong frame. The reel logo stays, recoloured plum and marigold.

Contrast. Hero text is plum on saffron (6.5:1); the chilli button has white text in light mode (4.6:1) and dark text in dark mode (6.2:1). Tokens: design/v3.0/tokens.json.
